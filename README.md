# My Personal Dashboard

A clean, minimal personal dashboard built with HTML, CSS, and vanilla JavaScript. No frameworks, no backend — everything runs in the browser with Local Storage.

## Features

| Feature | Details |
|---|---|
| **Greeting** | Shows your name, current time, and a greeting that changes based on the time of day |
| **Focus Timer** | Countdown timer (default 25 min). Start, Stop, Reset. |
| **To-Do List** | Add, edit, mark done, delete, and sort tasks. Saved to Local Storage. |
| **Quick Links** | Save and open your favourite websites with one click. |

## Challenges Implemented

- ✅ **Light / Dark mode** — toggle with the 🌙 button in the top bar
- ✅ **Custom name in greeting** — click ✏️ to set your name
- ✅ **Prevent duplicate tasks** — adding the same task (case-insensitive) shows a warning
- ✅ **Change Pomodoro time** — set any duration from 1–120 minutes
- ✅ **Sort tasks** — sort A→Z, Z→A, or done-last
